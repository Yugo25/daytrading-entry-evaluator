# 20EMA手法 エントリー評価スキル

## このスキルの目的

20EMA手法のエントリーが「基準を満たした適格なエントリーか」を、執行足チャート1枚から、固定の観察5要素と評価8要素（各軸4要素×2軸）で構造的に採点し、総合判定を出す。判定は常に同一フォーマットで出力し、結果論を排した客観評価に徹する。

評価の前提となる手法の核心:
- 本手法は **20/200EMAクロス後の初回押し目で、エリオット第3波を獲りにいく** ものである。「左側のトレンド転換波動＝第1波」「20EMAタッチの調整＝第2波」「タッチ足ブレイク＝第3波の入口」という対応で読む。
- 優位性の源泉は **「鋭い第一波」＋「クロス後初回のタッチ」**。だらだらした推進や、初回でない（何度も触っている）タッチは優位性が薄い。
- 最大の負け要因は **①待てない先回り（タッチ・実体ブレイク・ライン確定の前に飛び乗る）②ジリジリ横ばいの戻し（調整がスイングをつけずモメンタムが死ぬ）③200EMA直下のスクイーズ＋転換構造の不在（反発でなく200EMA逆ブレイクに化ける）**。これらは「気付けていてもエントリーしてしまう」ため、入る前に機械的に弾く採点が要る。
- 勝ち筋は **鋭い初回エクスパンション → スイングをつけた浅い戻し → 確定ブレイク → 転換波動内の明確な高安値をTPに**。TP基準が引けない＝RRが取れない＝見送り。

## 執行足について

- 基本の執行足は **5分足**。ただし **1分足・1h足でエントリーすることもある**。
- 執行足が1mや1hの場合も、本スキルの基準（観察5要素・評価8要素・採点表）を **そのまま適用** する。タイムフレーム不一致の注記は不要。
- **入力は執行足チャート画像のみ**。上位足の方向感・AOIの質は画像から判定できないため **採点対象外**（軸として持たない）。チャートに灰色ボックスで上位足AOIが写っていても、参考言及に留め採点には使わない。

## 入力チャートの読み取り規約

評価対象としてユーザーが与える執行足チャート画像（TradingView）は、以下の規約で読む:

- **緑のローソク = 陽線、黒のローソク = 陰線**
- **薄い青 = 20EMA、濃い青 = 200EMA**
- **緑の垂直線 = 最新のゴールデンクロス(GC)発生地点、オレンジの垂直線 = デッドクロス(DC)発生地点**（方向感確定の目印）
- **緑の印 = GC後はじめての20EMA/200EMAへの価格タッチ、オレンジの印 = DC後はじめてのタッチ**（＝クロス後初回タッチの目印。ここがSTEP4の調整波タッチに対応する）
- **灰色の線 = ①TP基準となる高安値（左側の転換波動内の押し安値/戻り高値）、②タッチ足の最高安値（＝エントリートリガーの基準価格）** を示す。価格水準を表す目印として読む。
- **灰色のボックス = 上位足のAOI**。執行足評価では参考情報。採点には用いない
- **緑/赤のボックス = エントリー**。境目が建値、**赤側が損切り(SL)方向、緑側が利確(TP)方向**。ロングなら赤が下・緑が上、ショートなら赤が上・緑が下

方向判定: GC(緑垂直線)＋緑印＝ロング想定、DC(オレンジ垂直線)＋オレンジ印＝ショート想定。エントリーボックスの赤/緑の上下とも整合するか確認する。

## 評価ワークフロー

### 観察フェーズ（固定5要素）

採点の前に、必ず以下の5要素を抽出して言語化する。分析もアウトプットも常にこの5要素で行う。

| 要素 | 抽出する内容 |
|---|---|
| ① クロス | 20/200EMAクロスの種別(GC/DC)・方向・位置。タッチ印が**クロス後初回**か（緑/オレンジ印の位置） |
| ② 第一波 | クロス後の推進波の方向・鋭さ・値幅（鋭いエクスパンションか、ジリ上げ/下げか）。第一波の高安値が形成され更新されずに戻っているか |
| ③ 転換波動・TP基準 | 左側に旧トレンド否定の高安値構造があるか。**TP基準の高安値(灰色線)が転換波動内に存在するか** |
| ④ 調整波 | 戻しの形（スイングをつける/横ばい・スクイーズ）、20EMAタッチの明確さ、200EMAとの距離 |
| ⑤ トリガー | タッチ足の最高安値(灰色線)を**実体で**ブレイク確定したか。トリガーラインを引くならスイング高安値を通るか。建値/SL/TPボックスの位置 |

### 採点フェーズ

各軸は4つの固定要素で判定する。要素ごとに **○(明確に満たす)/△(部分的・確認不足)/×(不適合)** を付け、軸スコアは換算表で決める。

## 軸1: 構造の質（第一波＋転換波動＋TP基準）

「第3波を獲るだけの土台（鋭い第一波と、TPを置ける転換波動）が出来ているか」を判定する軸。

| 記号 | 要素 | ○の基準 | ×の典型 |
|---|---|---|---|
| A1 | 第一波の鋭さ | クロス後に明確なエクスパンション（鋭い推進波）がある | ジリ上げ/ジリ下げ、推進と呼べない緩慢な動き |
| A2 | 第一波の完成 | 第一波の高安値が形成され、**更新されないまま**価格が戻ってきている | 第一波が観測できない/未完成、戻る前に高安値を更新 |
| A3 | 転換波動・TP基準 | 左側に旧トレンド否定の高安値構造があり、**TP基準の高安値(灰色線)が転換波動内にある** | 転換波動構造がない、またはTP基準が転換波動内に引けない |
| A4 | クロス整合・初回 | 20/200クロスが明確で、タッチが**クロス後初回**（緑/オレンジ印が初回位置） | クロスが曖昧、初回でない反復タッチ |

**中核要素はA1とA2**。どちらかが×なら軸1は自動的に2以下。
（A3の×は即見送り条件にも該当する点に注意 — 後述）

## 軸2: 調整・トリガーの質（最重要・負けの主因軸）

「戻しが本物の調整か（ビルドアップ/横ばいでないか）、ブレイクを確定で待てているか」を判定する軸。実トレードの負けはほぼこの軸の崩れに集約される。

| 記号 | 要素 | ○の基準 | ×の典型 |
|---|---|---|---|
| B1 | 戻しの形 | 調整がスイング高安値をつけながら戻り、再推進に向かう形 | **ジリジリ横ばい/スクイーズ**（モメンタム消失、200EMA舐め） |
| B2 | タッチの明確さ | 20EMAに明確にタッチ（緑/オレンジ印が明確） | タッチ位置が曖昧、「タッチしたとみなす」 |
| B3 | ブレイク確定 | タッチ足の最高安値(灰色線)を**実体で**ブレイク済み | 先回り、ヒゲ抜けのみ、ブレイク前に飛び乗り |
| B4 | トリガーライン質 | トリガーラインがスイング高安値を通る有効なライン | 最安値と近接点を結んだお粗末なライン、引けない |

**中核要素はB1とB3**。どちらかが×なら軸2は自動的に2以下。

## 軸スコア換算表（両軸共通）

| 軸スコア | 要素の状態 |
|---|---|
| 5 | 4要素すべて○ |
| 4 | ○3つ + △1つ（×なし） |
| 3 | ○2つ + △2つ（×なし）、**または非中核(A3/A4・B2/B4)の×が1つだけ**（他に×なし。△の有無に関わらず3に留める） |
| 2 | **中核要素(A1/A2・B1/B3)の×が1つ**（他に×なし） |
| 1 | ×が2つ以上、または完全な横ばい/スクイーズ/無理引き該当 |

判定は上から順に、最初に該当した行を採る。迷ったら低い方に倒す（手法自体が「見送り条件1つで入らない」保守設計のため）。

## 即見送り条件（手法の見送り条件＝総合「見送り」に直結）

観察で次のいずれかを認めたら、軸の点に関わらず総合を **1（見送り）** とする:

- 第一波が観測できない / 完成していない（A1またはA2が×）
- 左側にトレンド転換を確認できる波動構造がない
- **利確基準となる高安値が転換波動内に見られない**（TP基準が引けない＝RRが取れない）
- タッチ後の次の足で最高安値をブレイクした（調整失敗）

## 特則（200EMA警戒・最大警戒キャップ）

観察で次のいずれかを認めた場合、軸の点数に関わらず総合を **最大2に制限** する。手法の最大の負け要因群（反発がブレイクに化けるケース）に直結するため:

1. **200EMA直下スクイーズ**: 価格が200EMAとラインの間で圧縮・揉み合い。
2. **ジリジリ横ばいの戻し**: 調整がスイングをつけず、200EMAを舐めるように張り付きボラ収縮（B1=×と同症状）。

## 総合評価

総合点は **2軸の低い方を上限** とする（ゲート方式）。その後、即見送り条件・特則を適用する。

| 総合 | 判定 | 意味 |
|---|---|---|
| 5 | エントリー適格(模範級) | 模範例と同等の形 |
| 4 | エントリー適格(標準) | 有効なエントリー。通常通り執行可 |
| 3 | 要注意 | 形は成立するが弱点あり。追加確認（実体ブレイク確定待ち・戻しのスイング完成待ち）を推奨 |
| 2 | 見送り推奨 | 中核要素の崩れ、または特則該当。入らない |
| 1 | 見送り(明確な罠) | 横ばい/スクイーズ/先回り/即見送り条件該当。実トレードの負けパターン |

**RRの扱い**: 採点軸には含めないが、建値・SL・TPボックスとTP基準線から想定RRRを概算し、総合評価表に補足する。RRRが1:1未満なら、点数に関わらず実務上は見送り（優位性が消えている）旨を主因に記す。

## 出力フォーマット（厳守・逸脱禁止）

**出力先がチャットでもNotionでも、必ず下記テンプレートと完全に同一の構成・見出し・表構造で出力する。** 出力先で形式を変える、表を箇条書きに置き換える、セクションを統合/省略/並べ替えることはすべて禁止。

必須ルール:
1. **観察は必ず5行の表**（①〜⑤）。箇条書きへの置き換え禁止。
2. **軸1・軸2は必ず各4行の表**（A1〜A4 / B1〜B4）。見出しに「— X/5」のスコアを必ず含める。
3. 各軸の表の直後に**補足2〜3行**（文章）を置く。
4. 表の「根拠」欄は一言〜短文（目安15〜40字）。長文解説は補足に回す。
5. 末尾は「### 総合評価 — X/5（判定ラベル）」+ **判定根拠の5行固定表**（ゲート/特則/即見送り/RR/主因）で締める。総合**3以下のときだけ**、その直後に **改善提案の表**（弱点→改善トリガー）を置く。4以上では出さない。
   - 判定ラベルは固定5種(`適格(模範級)`/`適格(標準)`/`要注意`/`見送り推奨`/`見送り(明確な罠)`)から選ぶ。
   - 総合評価に散文段落を書かない（要点は「主因」欄に一言）。
   - 改善提案は△/×だった要素ごとに1行（点数を縛った要素を優先、最大3行）。
6. 方向（ロング/ショート、GC/DC、初回タッチ種別）は「## 20EMA手法 エントリー評価」直後の1行に書く。
7. Notion書き込み時に追加してよいのは末尾の評価日スタンプ1行のみ（例: `*評価日: YYYY-MM-DD / 20EMA手法 エントリー評価*`）。

## 評価時の注意（客観性・結果論禁止）

- **結果論で採点しない。** ブレイク後の値動きが画像に写っていても、評価は「ブレイク前の時点で基準を満たしていたか」に基づく。勝ちトレードでも形が悪ければ低評価、負けトレードでも形が正しければ高評価になりうる（「結果が勝ちでもプロセス不合格」を貫く）。
- **評価は常に基準に基づく。** 印象や「なんとなく良い/悪い」で点を動かさない。各要素は上表の○/×基準に当てはめて機械的に判定する。
- **トリガーラインが画像に引かれていない場合**は、まず「妥当なラインが引けるか」を診断する。引けるなら自分で引いた想定で評価、引けないならその事実をB4の低評価（無理引きしかできない＝見送り）として報告する。
- 上位足の情報（方向感・AOIの質）は本スキルの採点対象外であることを明記する。本スキルは執行足の20EMAエントリー品質のみを評価する。

## Notionページからのチャート画像取得（ページ指定のみで評価するフロー）

ユーザーがページ名だけを指定し、チャットに画像を添付していない場合は、ページから執行足画像を取得して評価する:

1. Notionのfetchツールで該当ページを取得する。ページの「## 執行足」セクション配下に執行足チャートの画像URL(`prod-files-secure.s3.us-west-2.amazonaws.com` の署名付きURL、有効期限1時間)が含まれる
2. bashで `curl -s -o /home/claude/chart_exec.png "<画像URL>"` でダウンロードし、`file` コマンドでPNG/JPEGであることを確認する
3. viewツールで画像を開いて評価を実施する
4. 「## 上位足」の画像は文脈の参考言及にのみ使い、採点には用いない

失敗時のフォールバック:
- ダウンロードが「Host not in allowlist」等で失敗した場合、ネットワーク許可リストに `prod-files-secure.s3.us-west-2.amazonaws.com` を追加するよう案内し（反映は新しい会話から）、当面はチャットへの画像アップロードを依頼する
- 署名付きURLは1時間で失効するため、失敗したらページを再fetchして新しいURLを取得してから再試行する

## 評価結果のNotionへの書き込み

ユーザーが書き込み先のNotionページを指定した場合（例: 「6/14-6/19の中の1.USDJPY」）、評価結果を該当ページに書き込む:

1. Notionの検索/fetchツールで指定された親ページ/子ページを探す（Trading Journal → 週レンジ名 → 通貨ペア名の階層が典型）
2. ページを取得し、テンプレートに用意された「AI評価」見出しを探す。評価結果はその見出しの下に書き込む。無ければページ末尾に「AI評価」見出しを作って書き込む
3. 書き込む内容は**出力フォーマットのテンプレートと一字一句同じ構成**。Notion用に再構成・要約・セクション追加をしない。末尾に評価日スタンプ1行のみ追加可
4. チャットにも**同一の評価結果**を表示し、Notionへの書き込み完了を一言添える

ページが見つからない・複数候補がある場合は、書き込まずに候補をユーザーに確認する。
